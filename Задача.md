# Практическое задание

## Паттерн Facade — Фасад

### Тема

Разработать систему запуска компьютерной игры с использованием паттерна **Facade**.

---

## 1. Задача

Создайте несколько независимых подсистем:

```text
GraphicsSystem
AudioSystem
InputSystem
SaveSystem
PlayerSystem
```

Каждая система должна иметь собственные методы.

Например:

```csharp
GraphicsSystem.Initialize();
AudioSystem.Initialize();
InputSystem.Initialize();
SaveSystem.Load();
PlayerSystem.Create();
```

---

## 2. Создайте GameFacade

Создайте класс:

```csharp
GameFacade
```

Он должен содержать ссылки на все подсистемы.

Например:

```csharp
private GraphicsSystem graphics;
private AudioSystem audio;
private InputSystem input;
private SaveSystem save;
private PlayerSystem player;
```

---

## 3. Метод StartGame()

В `GameFacade` создайте:

```csharp
public void StartGame()
```

Он должен самостоятельно выполнять все необходимые операции запуска:

```text
Инициализация графики
↓
Инициализация звука
↓
Инициализация управления
↓
Загрузка сохранения
↓
Создание игрока
↓
Запуск игры
```

---

## 4. Использование

В `Main()` нельзя вручную запускать каждую подсистему.

Вместо:

```csharp
graphics.Initialize();
audio.Initialize();
input.Initialize();
save.Load();
player.Create();
```

должно быть:

```csharp
GameFacade game = new GameFacade();

game.StartGame();
```

---

## 5. Добавьте остановку игры

Создайте:

```csharp
public void ExitGame()
```

Он должен корректно завершать игру.

Например:

```text
Сохранение игры
↓
Остановка игрока
↓
Остановка управления
↓
Остановка звука
↓
Остановка графики
↓
Игра завершена
```

---

## 6. Дополнительное задание

Добавьте ещё три подсистемы:

```text
InventorySystem
QuestSystem
NetworkSystem
```

Добавьте в Facade методы:

```csharp
StartGame();
PauseGame();
SaveGame();
ExitGame();
```

Каждый метод должен самостоятельно выполнять необходимую последовательность операций.

---

## 7. Усложнение

Добавьте возможность запуска новой игры:

```csharp
game.StartNewGame();
```

и загрузки существующей:

```csharp
game.LoadGame();
```

При этом клиентский код не должен самостоятельно обращаться к:

```text
SaveSystem
PlayerSystem
InventorySystem
QuestSystem
```

Он работает только через:

```text
GameFacade
```

---

## 8. Ограничения

Нельзя:

- удалять созданные подсистемы и переносить всю их логику в `GameFacade`;
- создавать один огромный класс вместо нескольких подсистем;
- вызывать подсистемы напрямую из `Main()`;
- делать отдельный Facade для каждой отдельной операции;
- использовать `if`/`switch` для имитации работы Facade.

Каждая подсистема должна оставаться отдельным классом.

## 10. Главное условие работы

`Main()` должен выглядеть максимально просто.

Например:

```csharp
class Program
{
    static void Main()
    {
        GameFacade game = new GameFacade();

        game.StartGame();

        Console.WriteLine();

        game.SaveGame();

        Console.WriteLine();

        game.ExitGame();
    }
}
```

При этом внутри `GameFacade` должны выполняться многочисленные операции различных подсистем.

### Главная идея работы

Клиент должен знать:

```text
GameFacade
```

но не обязан знать:

```text
GraphicsSystem
AudioSystem
InputSystem
SaveSystem
PlayerSystem
InventorySystem
QuestSystem
NetworkSystem
```

**Сложная система должна оставаться сложной внутри, но выглядеть простой снаружи.**
